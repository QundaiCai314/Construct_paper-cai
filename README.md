# Construct Paper CAI

A Codex skill for creating posters, illustrations, covers, interfaces, infographics, and other visual assets in a unified Constructivist paper sci-fi collage style.

The skill transforms creative briefs into dark, tactile compositions built from angular paper forms, geometric structures, archival textures, restrained typography, and a distinctive navy, bone-white, teal, and rusty-red palette.

The callable skill name is `$construct-paper-cai`.
