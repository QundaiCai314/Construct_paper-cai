# Visual Examples

Inspect the five images in `examples/` when creating icons, badges, compact interface marks, or tactile object symbols.

| File | Reference value |
|---|---|
| `08-upgrade-arrow.png` | Bold directional silhouette, layered paper facets, and one small orange signal |
| `09-combo-multiplier-base.png` | Radial structure, bone-white center, and alternating dark geometric segments |
| `10-offline-reward-archive-box.png` | Recognizable object built from simple folded planes and restrained depth |
| `11-publication-rebirth-badge.png` | Symbolic narrative assembled from a book, red core, leaves, and orbital lines |
| `12-scientist-target-marker.png` | Faceless identity mark framed by technical targeting geometry |

Use these examples to preserve:

- fibrous cut-paper surfaces and imperfect edges
- deep navy, bone-white, desaturated teal, rusty red, and limited orange
- compact silhouettes that remain readable at small sizes
- shallow physical layer shadows instead of glossy three-dimensional rendering
- geometric construction with one dominant action or symbol

Treat the examples as style anchors, not templates. Adapt the composition to the requested subject and do not reproduce an example unchanged.
